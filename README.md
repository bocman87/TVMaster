# TV MASTER — Android IPTV player

Самостоятельный Android-плеер для пользовательских M3U/M3U8-плейлистов. Не копирует IPTV Pro и не содержит встроенных телеканалов.

## Возможности стартовой версии
- Загрузка M3U/M3U8 по URL
- Поиск каналов
- Категории из `group-title`
- Избранное
- Воспроизведение через AndroidX Media3 / ExoPlayer
- Тёмный интерфейс с синими акцентами

## Сборка APK
1. Установите Android Studio с поддержкой Android Gradle Plugin 8.7.
2. Откройте папку `TVMaster` как проект.
3. Дождитесь синхронизации Gradle.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Для распространения создайте подписанную сборку через **Build → Generate Signed Bundle / APK**.

## Важно
Это исходный стартовый проект; APK не собран и не протестирован на физическом устройстве. EPG/XMLTV, локальный импорт плейлистов и сохранение нескольких плейлистов можно добавить следующей версией. Приложение не предоставляет каналы: используйте только легально полученные плейлисты и потоки.
